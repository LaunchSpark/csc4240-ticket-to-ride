# Using AI Tools to Beat ExampleBot in Ticket to Ride

**Project proposal draft — CSC [4240 or 5240], Artificial Intelligence**

**Motivation.** Our goal is to build a Ticket to Ride agent that consistently beats ExampleBot. ExampleBot is intended to be the simplest possible agent that meaningfully interacts with every game feature implemented by the engine. It provides a functional opponent against which improvements in planning, resource management, and competitive play can be measured. We will use available AI tools to find and implement whatever strategy most effectively achieves this goal.

**Description and methodology.** The repository already contains a Python game engine, seven bots, interactive marimo notebooks, game logs, and training scripts. We will use these tools to inspect losses against ExampleBot, identify weak decisions, and test improvements. Candidate approaches include AI-assisted heuristic design, search and simulation, probabilistic opponent modeling, and machine learning with existing libraries such as XGBoost. We may combine approaches or abandon them based on results. The objective determines the method; training a model is optional.

We will begin with two-player games on the classic map. Agents will choose legal actions using their own cards, tickets, and public game information. Our contribution will be the strategy development, integration of existing AI tools, and experimental evidence showing which changes help beat ExampleBot. We will document AI assistance and adapted sources, explain our choices, and retain unsuccessful approaches in the experiment record.

**Evaluation.** ExampleBot will be the primary benchmark, with its version fixed throughout each comparison. Our target is a head-to-head win rate above 50% on previously unused evaluation seeds, supported by uncertainty estimates across seed pairs. We will play each seed in both seat orders and control bot randomness separately. A pilot will determine the final game count before testing. We will report ties, score margins, ticket completion, and decision time alongside wins. Development and final evaluation seeds will remain separate; any learned models will also use separate training and validation games. Removing individual strategy components will help identify which changes improve performance. Other bots can provide secondary comparisons, but success is measured against ExampleBot.
